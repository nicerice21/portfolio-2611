# ポップな日常・恋愛アニメ風 背景デザインブリーフ

## デザインの方向性

- 基調は「オフホワイトの紙面」。
- 淡い水色、ピンク、クリーム色を少量ずつ重ね、青春らしい明るさを出す。
- 水彩のにじみ、薄い紙の粒子、少数の紙吹雪や小さな丸・三角を使う。
- 背景の装飾はページ上部またはヒーロー周辺に寄せ、本文へ向かって薄くする。
- 既存サイトの余白とシンプルさを残す。背景を主役にせず、文字と既存コンテンツを主役にする。
- 特定作品のロゴ、キャラクター、キービジュアルを複製せず、色・質感・モチーフの使い方だけを参考にする。

## 色と質感の目安

| 役割       | 色の目安           | 使い方                       |
| ---------- | ------------------ | ---------------------------- |
| ベース     | #FFFCF7            | ページ全体の背景             |
| 淡い空色   | #DDF2F7            | 大きく薄い水彩風の色面       |
| 淡いピンク | #F8E0E8            | 小さなアクセント、紙吹雪     |
| クリーム   | #FFF1C9            | 光や温かさのアクセント       |
| ミント     | #E2F1E6            | 必要な場合だけ補色として使用 |
| 本文色     | 既存の文字色を維持 | コントラストを保つ           |

色は不透明度を下げて使い、装飾が文字やボタンの視認性を損なわないようにする。既存テーマに色変数がある場合は、新しい固定色を増やす前に既存トークンへ合わせる。

## 背景レイヤー案

1. **土台**：既存のページ背景色を活かし、必要なら温かみのあるオフホワイトに調整する。
2. **大きな色面**：画面端に、ぼかした水色とクリーム色の色面を1〜2個置く。中央の本文領域は薄く保つ。
3. **微細な質感**：粒子や紙目を低い不透明度で追加する。画像素材を使う場合は軽量なものを使い、読み込みに失敗しても背景色だけで成立させる。
4. **小さな装飾**：ピンクや水色の点、短い線、紙吹雪を少数だけ配置する。ランダムに見える場合も、文字の近くには置かない。
5. **コンテンツ**：既存のカード、見出し、ボタン、ナビゲーションの前後関係と配置を維持する。

## 組み込みルール

- まず既存ページの構造、背景色、重なり順、レスポンシブ指定を確認する。
- 変更範囲は背景色、背景レイヤー、必要最小限の装飾用要素に限定する。
- 既存のDOMやレイアウトを大きく組み替えない。新しいセクションやナビゲーションは追加しない。
- 装飾レイヤーはコンテンツの背面に置き、クリックを妨げないようにする（例：pointer-events: none）。
- 装飾目的の要素は支援技術から隠す（例：aria-hidden="true"）。
- 小さい画面では装飾の数や濃さを減らし、横スクロールを発生させない。
- 動きを加える場合は必須にせず、控えめにする。prefers-reduced-motion が有効な場合は停止する。
- 新しいライブラリや大きな画像を追加しない。既存のスタックと仕組みを優先する。
- 背景を外してもページが正しく読める状態を保つ。
